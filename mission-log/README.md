# mission-log

Frontend de **Flow Work Logger**. Vue 3 + TypeScript + Vite + Tailwind CSS.

Ver [AGENTS.md](./AGENTS.md) y [CLAUDE.md](./CLAUDE.md) — la arquitectura de carpetas todavía está en definición.

## Setup

```bash
pnpm install
cp .env.example .env   # completar con tus valores locales
pnpm dev
```

## Scripts

| Comando | Descripción |
| --- | --- |
| `pnpm dev` | Servidor de desarrollo |
| `pnpm build` | Type-check + build de producción |
| `pnpm preview` | Sirve el build de producción localmente |
